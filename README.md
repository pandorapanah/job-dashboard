# job-dashboard

گزارش بی‌نام و عمومی برای جست‌وجوی کار. صفحهٔ اول همیشه تازه‌ترین نسخهٔ موجود را نشان می‌دهد و نسخه‌های قبلی در بایگانی ثابت می‌مانند.

این ریپازیتوری فقط خلاصهٔ عمومی `public-jobsearch-summary` نسخهٔ ۱ را می‌پذیرد. نام، راه‌تماس، رزومه، جواب فرم و وضعیت درخواست هر آگهی این‌جا نمی‌آید. کتابخانهٔ آگهی‌ها از جمع‌بندی درخواست‌ها جداست و نمی‌گوید برای کدام آگهی درخواستی رفته است.

به‌روزرسانی فقط دستی است. هیچ زمان‌بندی‌ای برای جمع‌آوری آگهی یا انتشار گزارش وجود ندارد.

## یک خلاصهٔ تازه

فایل ورودی باید همان طرح عمومی باشد. اعتبارسنج، فیلد اضافه یا فیلد خصوصی را قبل از هر نوشتن رد می‌کند. اگر رد شود، بایگانی و سایت دست نمی‌خورند.

```sh
node scripts/publish-report.mjs --input path/to/summary.json
```

نسخهٔ قبلی سر جایش می‌ماند. صفحهٔ اول به نسخهٔ تازه می‌رود.

## بازبینی همان گزارش

برای ثبت یک کنترل روی همان عددها، بدون ساختن گزارش روز بعد و بدون ارسال تازه:

```sh
node scripts/publish-report.mjs --revision-check --snapshot SNAPSHOT_ID
```

زمان بازبینی از ساعت همان لحظه گرفته می‌شود. خلاصهٔ اصلی عوض نمی‌شود.

## آزمون و ساخت

```sh
node --test
node scripts/build-site.mjs
node scripts/privacy-gate.mjs
```

دادهٔ نمونه فقط زیر `test/fixtures` است، با برچسب `EXAMPLE-ONLY-NOT-A-REAL-VACANCY`، و اجازهٔ ورود به آرشیو واقعی را ندارد.
